# 💜 Finora — Personal Finance Dashboard

A modern and responsive personal finance dashboard designed to help users track their income, expenses, transactions, and budget in one place.

## 📌 About the Project

**Finora** is a frontend web development project that provides a simple and interactive interface for managing personal finances. It helps users monitor their financial activity, review transactions, and understand their spending habits through a clean dashboard.

## ✨ Features

* 📊 **Financial Overview** — View total balance, income, expenses, and transactions.
* 💳 **Transaction Management** — Add and delete transactions.
* 🔍 **Search & Filter** — Find transactions and filter them by category.
* 📈 **Visual Analytics** — View financial data through charts.
* 🎯 **Budget Tracking** — Monitor spending against a budget.
* 🌙 **Dark Mode** — Switch between light and dark themes.
* 💾 **Local Storage** — Save transaction data in the browser.
* 📱 **Responsive Design** — Designed to work across desktop and mobile screens.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage API
* Chart.js (if included in your project)
